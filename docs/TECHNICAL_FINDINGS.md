# Technical findings and provenance

Addresses prefixed `0x` in this document and `TEXT_CONSUMERS.csv` are **ROM file offsets** unless explicitly stated otherwise. Credit destinations such as `0x59E0` are offsets in the native decompression destination context in the S455/S457 source metadata; their physical RAM or VRAM mapping is not established here. CPU and segmented addresses have not been inferred from file banks.

## Credit graphic resources and destinations

The exact 14 block descriptors, compressed SHA-256 values and destination contexts live in `source/Riviera_S457_FULL_SOURCE/source/RELEASE.json` and `S455_RELEASE.json`. The hook is a ROM offset; the destination values in those JSON records belong to the renderer's buffer context. The source does not establish a universal CPU/segmented/VRAM conversion for them. The code documents RLE decoding, packed glyph data and the bounds of the stub and payload.

## Historical documentation retained

The S456 archive and its upstream chain contain the original reports, tables, source scripts, traces and in-context evidence through the earlier stages. Their prior validation statements apply only to the precise dependency and scope described. `docs/ORGANIZATION_MANIFEST.json` records every removed savestate and bytecode file, all rewritten archive digest references and the original paths. Historical per-file manifests were preserved as evidence of the original archives and do **not** certify the sanitized archive byte identities.
