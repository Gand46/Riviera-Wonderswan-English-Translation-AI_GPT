# v0.112-S459-RC3 release notes

Experimental manual-testing RC3. Seven Chapter 8 Hades streams were translated and four epilogue page layouts were rebalanced. The BPS is a direct cumulative patch from the identified clean Japanese ROM; its bytes are unchanged from the supplied release. The source archive was sanitized for publication by removing savestates and generated bytecode, which changes its archive hashes, not the translation patch.

**Known issues:** Japanese remains visible in a later ending scene; the ninth icon consumer, three credit-name readings and independent 32-page epilogue visual review are unresolved. `FINAL_APPROVED=false`. Prior source/BPS equality is documented, while a fresh rebuild of the sanitized archive is NOT_RUN without the clean ROM. See `BUILD_AND_REPRODUCIBILITY.md`.
